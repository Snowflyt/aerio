# Aerio

A clean asynchronous runtime for TypeScript.

Aerio is a lightweight runtime for writing reliable asynchronous applications in TypeScript. It implements a tiny, fast and pure [IO monad](#what-is-an-io-monad) with a rich set of combinators and utilities for handling asynchronous computations, errors, and cancellations in a composable and type-safe way.
